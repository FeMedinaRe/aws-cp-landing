Los 4 dominios del examen

Haz clic en cada dominio para desplegar sus temas de estudio. Los pesos indican la ponderación en el examen.

Ponderación: 20%
  • Pago por uso: solo pagas lo que consumes (OpEx en lugar de CapEx).
  • Elasticidad y escalabilidad: aprovisiona recursos según la demanda.
  • Alta disponibilidad: distribuida en múltiples regiones y zonas de disponibilidad (AZ).
  • Innovación acelerada: prueba nuevos servicios sin inversión inicial.
  • Infraestructura global: regiones, AZ, ubicaciones de borde y puntos de presencia (PoP).
  • AWS (seguridad DE la nube): centros de datos, hardware, hipervisor, red física.
  • Cliente (seguridad EN la nube): datos, credenciales IAM, configuración de red y aplicaciones.
  • Cambia según servicio: gestos de servicios como S3 o RDS trasladan más responsabilidad a AWS.
  • Nube pública: recursos compartidos entre distintos clientes (AWS).
  • Nube privada: infraestructura exclusiva de una organización.
  • Nube híbrida: combina on-premises y nube, ideal para migraciones graduales.
  • Excelencia operativa: automatiza operaciones y documenta procesos.
  • Seguridad: mínimo privilegio, cifrado y trazabilidad (p. ej. CloudTrail).
  • Fiabilidad: planifica fallos, redundancia y recuperación.
  • Rendimiento: selecciona servicios adecuados y optimiza.
  • Optimización de costos: elimina recursos ociosos y usa modelos con descuento.
Ponderación: 24%
  • Usuarios, grupos y roles: identidades que reciben permisos.
  • Políticas: documentos JSON con Allow/Deny.
  • MFA: autenticación multifactor como capa extra de seguridad.
  • Principio de mínimo privilegio: solo los permisos necesarios.
  • Roles: para servicios, federación y acceso temporal (STS).
  • KMS: gestión centralizada de claves de cifrado.
  • CloudTrail: registra todas las llamadas a la API (auditoría).
  • Macie: detecta y clasifica datos sensibles en S3.
  • Secrets Manager: rota secretos y evita credenciales hardcodeadas.
  • GuardDuty: detección proactiva de amenazas.
  • AWS Artifact: acceso a informes y contratos de cumplimiento.
  • Marcos soportados: ISO 27001, SOC, PCI DSS, HIPAA, GDPR.
  • AWS Config: evalúa configuraciones de recursos frente a reglas.
  • Certificaciones regionales: varían según región e industria.
  • Network ACL (subred): filtros stateless de tráfico entrante y saliente.
  • Security Groups (instancia): firewall stateful a nivel de instancia.
  • Web ACL: filtros de aplicación protegidos por AWS WAF.
Ponderación: 34%
  • EC2: máquinas virtuales (instancias) con AMIs, tipos de instancia y Auto Scaling.
  • EC2 Auto Scaling: ajusta automáticamente la capacidad según la demanda.
  • Lambda: serverless, ejecuta código por eventos, cobra por ejecución.
  • ELB: equilibra el tráfico entre instancias (Application/Network/Gateway LB).
  • S3: almacenamiento de objetos, durable y con clases como S3 Standard, Infrequent Access y Glacier (archivo).
  • EBS: volúmenes de bloques conectados a EC2.
  • EFS: sistema de archivos compartido para múltiples instancias (NFS).
  • S3 Glacier: almacenamiento de archivo de bajo costo para copias de seguridad.
  • RDS: bases relacionales gestionadas (MySQL, PostgreSQL, SQL Server, Oracle).
  • Aurora: base relacional compatible con MySQL/PostgreSQL de alto rendimiento.
  • DynamoDB: base NoSQL de clave-valor sin servidores que gestionar.
  • Redshift: data warehouse para análisis a gran escala.
  • VPC: red privada virtual con subredes y tables de ruta.
  • Route 53: servicio DNS gestionado.
  • CloudFront: CDN que ofrece contenido con baja latencia desde el borde.
  • VPN y Direct Connect: conexión segura con infraestructura on-premises.
  • CloudFormation: plantillas JSON/YAML que aprovisionan stacks de recursos.
  • Elastic Beanstalk: despliegue de aplicaciones con capa de gestión automática.
  • Systems Manager: gestión y automatización de operaciones.
Ponderación: 22%
  • TCO: costo total de propiedad (hardware, energía, data center, personal, operación).
  • CapEx → OpEx: la nube convierte inversión de capital en gasto operativo.
  • AWS TCO Calculator: compara costos on-premises vs. AWS.
  • On-Demand: pago por uso, flexible, sin compromiso.
  • Reserved / Savings Plans: ahorro por compromiso de 1 o 3 años.
  • Spot: descuentos para cargas interrumpibles; pueden ser reclamadas.
  • Free Tier / pruebas: siempre gratuito, 12 meses o pruebas por servicio.
  • Cost Explorer: visualiza y analiza el gasto histórico.
  • Budgets: alertas y límites de gasto (costo, uso, RI, Savings Plans).
  • Consolidated Billing: facturación unificada de varias cuentas (AWS Organizations).
  • Trusted Advisor: recomienda optimizaciones (incluida la reducción de costos).
  • AWS Pricing Calculator: estima costos mensuales antes de desplegar.
  • Precios por región: los costos varían según región; elige la adecuada.
  • Reduce costos: apaga recursos sin uso, dimensiona y aprovecha descuentos.
